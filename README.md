# 🌙 MOON-MD WhatsApp Bot

Advanced Multi Device WhatsApp Bot with AI, Group Tools, Downloaders, Pair Code System and Dark Hacker Menu.

Deployable on Render, Railway, VPS and Termux.

---

## ⚡ Features

- Multi Device Support  
- Pair Code Login  
- AI Commands  
- Group Management  
- Anti Link System  
- Welcome & Goodbye  
- Sticker Commands  
- Music Search  
- TikTok Tools  
- Owner Commands  
- Dark Hacker Menu  
- Deploy Ready
